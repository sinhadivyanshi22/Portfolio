# Divyanshi Sinha — Portfolio

My personal portfolio website showcasing my skills, projects, certifications, and coding journey.

## Tech Stack
- HTML, CSS, JavaScript
- Node.js and Express.js
- Resend API

## Features
- Responsive dark theme
- About me and skills
- Projects and certifications
- GitHub contribution calendar
- LeetCode activity calendar
- Contact form with email integration

## Run Locally

```bash
git clone https://github.com/sinhadivyanshi22/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Configure the required environment variables for the backend before using the contact form.
