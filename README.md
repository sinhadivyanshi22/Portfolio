## Run Locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/sinhadivyanshi22/Portfolio.git
cd Portfolio
```

Or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
